# 결제 모듈 도입 — 운영자 정보 요청서

**문서 목적**: Get It Done at Work 사이트에 온라인 결제(토큰 자동 발행) 기능을 붙이기 위해, 운영자(사업 책임자)가 준비·결정해야 할 정보를 한 번에 정리한 문서.

**대상 독자**: 사이트 운영자 (개발 지식 없어도 OK)
**작성 주체**: 개발자 (Luke / XRX)
**최종 업데이트**: 2026-05-08

---

## 0. 한 장 요약 — 무엇이 일어나는가

```
[고객] → 사이트에서 패키지 선택 → 카드 결제 (Stripe 또는 Polar)
   ↓
[결제사 webhook] → 사이트 자동으로 토큰 충전 (관리자 손 안 대도 됨)
   ↓
[고객] → 충전된 토큰으로 1:1 매칭 신청 → Enabler 수락 → 세션 진행
```

**관리자가 할 일은 패키지(가격-토큰 비율)를 처음 한 번 설정하는 것뿐.** 결제 발생할 때마다 자동 부여됩니다.

## 1. 가장 먼저 결정해주세요 — Stripe vs Polar

두 결제사 중 하나를 선택해야 합니다. 둘 다 한국 사업자가 가입 가능합니다.

### 한눈 비교

| 기준 | **Stripe** (추천) | **Polar** |
|------|--------------------|-----------|
| 결제 수수료 | 약 2.9% + 300원/건 | 약 4% + 400원/건 |
| 한국 결제수단(KakaoPay·Toss) | 지원 | 카드 위주 |
| 세금·VAT 처리 | 직접 (또는 Stripe Tax 별도 가입) | **자동** (Polar가 대신 처리) |
| 인보이스/세금계산서 | 별도 설정 | 자동 발행 |
| 가맹 심사 | 평균 1~2주 | 평균 2~3일 |
| 안정성 | 글로벌 표준 | 신생 (2024) |
| B2B 기능 (조직 일괄결제 등) | 강력 | 기본 |

### 어느 쪽이 맞나?

| 우리 상황 | 추천 |
|-----------|------|
| 한·미 양국에서 정식 운영, 매출 규모를 키울 계획 | **Stripe** |
| 사업자등록·세금 처리 부담을 줄이고 빠르게 베타 매출 확인 | **Polar** |
| 매월 매출 500만원 이상 예상 | **Stripe** (수수료 차이 누적이 큼) |
| 매월 매출 500만원 미만, 일단 시장 검증 | **Polar** (세금 처리 위탁이 편함) |

**※ 개발자 의견**: 현재 사이트가 한·미 양국 타겟 + B2B 매칭 서비스라서 **Stripe**를 우선 추천. Polar는 빨리 시작하는 대신 수수료가 크고 한국 결제수단(카카오페이/토스 등)이 약합니다.

→ **선택 결과**: ☐ Stripe ☐ Polar

## 2. Stripe를 선택한 경우 — 필요 정보

### 2-1. 사업자 정보 (Stripe 가맹 심사용)

Stripe 가입 시 입력해야 합니다. 정확하게 알려주세요.

- [ ] **사업자등록번호** (한국 — 사업자등록증 사본 또는 번호)
- [ ] **대표자 성명** (등록증과 일치)
- [ ] **대표자 생년월일**
- [ ] **대표자 신분증 사진** (주민등록증 또는 여권 — Stripe가 KYC로 요청)
- [ ] **사업장 주소** (등록증 주소)
- [ ] **연락 가능한 전화번호**
- [ ] **연락 이메일** (Stripe 알림 수신용)
- [ ] **법인의 경우**: 법인등기부등본, 임원 명단, 지분 정보

### 2-2. 정산 받을 계좌

- [ ] **은행명**
- [ ] **계좌번호**
- [ ] **예금주명** (사업자명과 일치 권장)
- [ ] **SWIFT 코드** (해외 결제 받을 경우 — 은행에 문의 가능)

> 한국 은행 계좌 등록 시 정산은 KRW로, 미국 은행 등록 시 USD로 받습니다. 양쪽 다 등록 가능.

### 2-3. 사이트·서비스 정보

- [ ] **서비스 한 줄 설명** (예: "한국 스타트업과 미국 진출 전문가를 1:1 매칭하는 컨설팅 플랫폼")
- [ ] **서비스 카테고리** (Stripe 분류 — "Professional Services" 또는 "Consulting" 정도)
- [ ] **공식 도메인**: `https://getitdonework.com` (변경 없음)
- [ ] **고객센터 이메일** (예: `support@getitdonework.com`)
- [ ] **고객센터 전화번호** (선택)

### 2-4. 환불 정책 본문 (필수)

Stripe는 환불정책 페이지가 사이트에 있어야 가맹 심사를 통과시킵니다. **현재 사이트 `/refund` 페이지는 비어 있습니다.** 운영자가 다음 기준으로 본문을 정해주세요.

- [ ] **미사용 토큰의 환불 가능 기간**: 결제 후 \_\_\_일 이내
- [ ] **부분 환불 정책**: 일부 사용한 토큰은 환불 가능? (예: 구매 10토큰 중 3개 사용 → 7개 비례 환불 OK / 환불 불가)
- [ ] **세션 취소 정책**:
  - 세션 24시간 전 취소 → 100% 환불 (현재 코드에 이미 있음)
  - 24시간 이내 취소 → ___% 환불
  - 노쇼 → 환불 불가 (권장)
- [ ] **환불 처리 기간**: 카드사 영업일 기준 \_\_\_일
- [ ] **환불 방법**: 결제 카드로 자동 환불

### 2-5. 결제 패키지 가격 정책

운영자가 처음 등록할 토큰 패키지를 정해주세요. 이후 어드민 페이지에서 변경 가능.

> 참고: 현재 1 토큰 = 30분 컨설팅 기준. Standard 세션 2토큰, Project 세션 5토큰 (시스템 설정값).

| 패키지명 | 토큰 수 | 가격 (KRW) | 가격 (USD) | 1토큰당 단가 | 비고 |
|----------|---------|------------|------------|--------------|------|
| Starter   |         |            |            |              | 처음 사용자용 |
| Standard  |         |            |            |              | 가장 많이 팔릴 것 |
| Pro       |         |            |            |              | 할인 적용 |
| Enterprise|         |            |            |              | 대량/조직 |

- [ ] 위 표 채워서 회신
- [ ] 통화: 한국에서만 판매 → KRW만 / 양국 판매 → USD/KRW 둘 다 등록

### 2-6. 부가세·세금 계산서

- [ ] **한국 고객 대상 부가세 10% 별도 부과 여부** (B2B는 세금계산서 발행 필요)
- [ ] **세금계산서 발행 의무 사업자 여부** (간이/일반/면세 — 사업자등록증에 표시)
- [ ] **미국 고객 대상 sales tax** (주별로 다름 — Stripe Tax 사용 권장)

> 결정 어려우시면 세무사와 상담 후 회신. 이 항목은 결제 붙이는 코드에는 영향 없고, Stripe 설정에서 별도로 처리합니다.

## 3. Polar를 선택한 경우 — 필요 정보

Polar는 Merchant of Record(MoR) 모델이라 **Polar가 운영자 대신 부가세·인보이스를 처리**합니다. 운영자 부담이 작습니다.

- [ ] **사업자명** (개인사업자 가능, 법인 권장)
- [ ] **대표자 이메일**
- [ ] **GitHub 계정** (선택 — 가입 시 편리)
- [ ] **정산 받을 계좌** (Stripe Connect 통해 처리 — 결국 위 2-2 정보 동일하게 필요)
- [ ] **서비스 설명·도메인** (위 2-3 동일)
- [ ] **환불 정책 본문** (위 2-4 동일)
- [ ] **결제 패키지 가격 정책** (위 2-5 동일)

> Polar 선택 시 **부가세·세금계산서 처리는 자동**이므로 위 2-6 항목은 생략 가능.

## 4. 공통 — 결제 통과 후 사이트 동작 방식 (참고)

운영자가 알면 좋은 흐름입니다. 결제 모듈 붙인 후의 동작.

### 4-1. 고객 입장에서

1. `/credits` 페이지에서 패키지 카드 보기
2. "구매하기" 버튼 → Stripe(또는 Polar) 결제창으로 이동 (사이트 외부)
3. 카드 결제 완료 → 자동으로 사이트로 돌아옴
4. **즉시 토큰이 잔액에 반영됨** (보통 5초 이내)
5. `/enablers`에서 원하는 Enabler 선택 → 1:1 매칭 신청

### 4-2. 관리자 입장에서

1. `/admin/credit-packages` 에서 패키지 추가/수정 (가격, 토큰 수, 활성화)
2. `/admin/credits` 에서 모든 결제·사용 이력 audit log 조회
3. 환불 필요 시 `/admin/credits` 에서 거래 선택 → "환불" → Stripe 자동 환불 + 토큰 회수
4. 매월 매출 보고서는 Stripe(또는 Polar) 대시보드에서 직접 다운로드

### 4-3. 자동 처리되는 것 (사람 손 안 대도 됨)

- 결제 성공 → 토큰 자동 충전
- 결제 실패 → 토큰 미충전 + 고객에게 자동 안내
- 부분 환불 → 사용 안 한 만큼 토큰 자동 회수
- 영수증 이메일 → Stripe(또는 Polar)가 자동 발송

**결제 가능 오픈까지 총 2~3주 (가장 큰 변수는 Stripe 가맹 심사 기간)**

## 7. 부록 — 자주 묻는 질문

**Q. 결제 수수료는 누가 부담하나요?**
A. 결제사가 정산 시 자동 차감합니다. 고객이 보는 가격은 패키지 정가 그대로입니다. 즉, 100,000원 결제 → 운영자 정산 약 96,800원 (Stripe 기준).

**Q. 사업자등록 없이 일단 시작 가능한가요?**
A. **Polar는 가능** (개인 명의로 시작 후 추후 사업자 전환 OK). **Stripe는 사업자등록 필수**. 단 Polar도 향후 매출 늘면 사업자등록 권장.

**Q. 한국 카드 결제는 모두 잘 되나요?**
A. Stripe는 비자/마스터/JCB 다 OK. KakaoPay·Toss는 별도 활성화 신청 필요. Polar는 카드 결제만 안정적이고 한국 PG 연동은 약함.

**Q. 환불 시 토큰은 어떻게 처리되나요?**
A. 사용 안 한 토큰만큼 자동으로 회수됩니다. 이미 사용한 세션의 토큰은 환불 불가 (코드에 이미 구현 예정).

**Q. 결제사 변경하려면?**
A. 가능하지만 권장 안 함. 한 번 정한 결제사에서 6개월 이상 운영 후 매출 보고 결정하는 게 안전합니다.

**Q. 결제 데이터는 안전한가요?**
A. 카드 정보는 사이트 서버에 절대 저장되지 않습니다. Stripe(또는 Polar)가 PCI-DSS 인증 환경에서 처리합니다. 사이트는 결제 ID·금액·상태만 저장.

## 8. 우선순위 추천

운영자 회신을 기다리는 동안 **가장 빠르게 결제 베타 시작하려면**:

1. **Polar 선택** (가맹 심사 2~3일)
2. 환불정책: "구매 후 7일 이내 미사용 토큰 100% 환불, 사용된 토큰은 환불 불가" (안전한 표준 정책)
3. 패키지 4종 시작:
   - Starter: 5토큰 / $30
   - Standard: 15토큰 / $80 (1토큰당 $5.33)
   - Pro: 35토큰 / $170 (1토큰당 $4.86)
   - Enterprise: 100토큰 / $400 (1토큰당 $4)
4. 통화: USD 우선 (한국 고객은 카드 자동 환전)

이대로 가면 운영자 회신 후 **3~4일 내 결제 베타 오픈 가능**.
