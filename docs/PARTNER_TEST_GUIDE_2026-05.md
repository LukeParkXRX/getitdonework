# Get It Done at Work — 파트너 테스트 가이드 (2026년 5월)

**테스트 사이트**: https://getitdonework.com
**테스트 가능 기간**: 즉시 ~
**문제 회신**: luke@xrx.studio (스크린샷 + 어떤 페이지에서 어떤 행동 시 문제 발생했는지 적어주세요)

---

## 테스트 계정 (베타 한정 — 빠른 로그인용)

`/login` 페이지 하단에 **테스트 로그인 패널**이 떠 있습니다 (베타 동안만).
원하는 역할 버튼 한 번 클릭하면 자동 로그인됩니다.

- **Super Admin** (관리자) — 모든 권한
- **Startup** (스타트업) — 한국 스타트업 사용자
- **Enabler** (전문가) — 미국 전문가 사용자
- **Org Admin** (기관) — 액셀러레이터 등 기관 어드민

본인 이메일로 직접 회원가입도 OK입니다 (`/signup`).

## 테스트 흐름 — 역할별

### A. 비회원 (방문자)

**A-1. 첫 방문 인상**
- [ ] 홈 (`/`) 진입 → 로딩 빠른가? 첫 인상 어떤가?
- [ ] 한국 IP에서 한국어로 자동 표시되는가?
- [ ] (가능하면) VPN으로 미국 IP 접속 → 영어로 자동 변경되는가?
- [ ] 우상단 KO/EN 토글 클릭 → 언어 즉시 바뀌는가?

**A-2. Enabler 둘러보기**
- [ ] `/enablers` 진입 → Enabler 카드들이 잘 표시되는가?
- [ ] 카테고리 필터 클릭 (B2B SaaS, Fintech 등) → 즉시 필터링 되는가?
- [ ] 검색바에 이름·대학 입력 → 결과 잘 나오는가?
- [ ] 정렬 dropdown 변경 (추천순 → 평점순 등) → 순서 바뀌는가?
- [ ] 페이지가 12명 넘어가면 다음 페이지 버튼 동작하는가?
- [ ] Enabler 카드 클릭 → 상세 페이지 (프로필·리뷰) 잘 보이는가?

**A-3. 정보 페이지**
- [ ] `/about`, `/cases`, `/insights`, `/faq`, `/program`, `/credits` 모두 빠르게 로드되는가?
- [ ] 모바일 (스마트폰)에서도 레이아웃 깨지지 않는가?
- [ ] `/contact` 폼 제출 → 성공 메시지 뜨는가?
- [ ] `/enabler-apply` 폼 제출 (Enabler 지원) → 완료 화면 보이는가?

### B. 스타트업 (한국 사용자)

**B-1. 회원가입·로그인**
- [ ] `/signup` → 이메일+비밀번호 가입 가능한가?
- [ ] 가입 완료 후 확인 이메일 도착하는가?
- [ ] `/login` → Google 로그인 가능한가?
- [ ] `/forgot-password` → 이메일 입력 → 재설정 링크 도착하는가?

**B-2. 첫 진입 (`/my`)**
- [ ] 토큰 잔액 카드가 가장 위에 보이는가?
- [ ] 신규 사용자라면 **온보딩 체크리스트** (4단계)가 보이는가?
- [ ] **"Enabler 둘러보기"** 큰 버튼이 잘 보이는가?

**B-3. Enabler 매칭**
- [ ] `/enablers` 에서 마음에 드는 Enabler 클릭
- [ ] 상세 페이지에서 **"매칭 신청"** 버튼 클릭
- [ ] 브리프 작성 → 제출 → 토큰 차감되는가?
- [ ] `/my` 또는 `/bookings` 에서 **"응답 대기 중"** 상태로 표시되는가?
- [ ] 동시에 인앱 알림(종 아이콘)에도 표시되는가?

**B-4. 메시지**
- [ ] Enabler 상세 페이지의 **"1:1 메시지 보내기"** 클릭 → 채팅방 진입
- [ ] 메시지 입력 + Enter → 즉시 보내지는가?
- [ ] `/messages` 에서 대화 목록 보이는가?
- [ ] 상대방이 답장하면 화면이 자동 갱신되는가? (실시간)

**B-5. 프로젝트 등록**
- [ ] `/projects/new` → 새 프로젝트 등록 (제목·카테고리·기간·예산·요구사항)
- [ ] `/projects` 에서 등록한 프로젝트가 카드로 보이는가?
- [ ] 카드 클릭 → 상세 → 편집 → 저장 → 반영되는가?
- [ ] 삭제 버튼 → 확인 다이얼로그 → 삭제되는가?

**B-6. 프로필 설정 (`/settings`)**
- [ ] 회사명·업종·단계 입력 후 저장 → 다음 진입 시 그대로인가?
- [ ] 알림 설정 토글 (세션·크레딧·마케팅) → 저장되는가?

**B-7. 분쟁 신청 (옵션)**
- [ ] 완료된 booking이 있다면 **"분쟁 신청"** 버튼 클릭
- [ ] 사유 select + 상세 입력 → 제출 → 성공 토스트
- [ ] 관리자가 처리 후 알림 받는가?

### C. Enabler (미국 전문가)

**C-1. 지원 → 가입 흐름**
- [ ] 비회원 상태에서 `/enabler-apply` → 지원서 제출
- [ ] 관리자 승인 후 본인 이메일로 가입 링크 도착
- [ ] 링크 클릭 → 가입 완료 → **자동으로 Enabler 권한 + 프로필 채워짐 + 환영 메시지**

**C-2. Enabler 대시보드 (`/enabler-dashboard`)**
- [ ] **Getting Started 카드** (3단계) 보이는가?
  - 프로필 작성 / 가용시간 / 정산 계정
- [ ] 미완료 항목 클릭 → 해당 페이지로 이동하는가?
- [ ] 이번 달 수익 / 총 수익 표시되는가?

**C-3. 프로필 작성**
- [ ] `/enabler-dashboard/profile` → 자기소개·전문분야·시간당 단가 저장
- [ ] `/enablers` 공개 페이지에서 본인 카드 확인 (프로필 잘 노출되는가?)

**C-4. 가용시간 설정**
- [ ] `/enabler-dashboard/availability` → 요일별 시간대 설정
- [ ] 저장 → 다시 진입 시 유지되는가?

**C-5. 정산 계정 (Stripe Connect — 정식 가맹 후 활성)**
- [ ] `/enabler-dashboard/payouts` → "Stripe 정산 계정 만들기" 버튼

**C-6. 매칭 요청 응답**
- [ ] 스타트업이 매칭 신청하면 알림이 오는가?
- [ ] `/enabler-dashboard` 에서 대기 매칭 요청 카드 보이는가?
- [ ] 수락 / 거절 버튼 동작하는가?

**C-7. 정산 내역**
- [ ] `/enabler-dashboard/earnings` → 본인 적립 내역 (세션별) 보이는가?
- [ ] 누적 / 인보이스 / 지급 완료 합계 표시되는가?

### D. Super Admin (운영자)

`/login` 에서 Super Admin 버튼으로 로그인 → 좌측 사이드바 **5개 카테고리** 메뉴 확인.

**D-1. 대시보드 (`/admin/dashboard`)**
- [ ] 30일 차트 3개 (신규 사용자 / 세션 / 매출) 보이는가?
- [ ] 대기 알림 배지 (Enabler 지원·문의·결제 승인) 클릭 → 해당 페이지로 이동
- [ ] 최근 결제 내역 5건 표시되는가?

**D-2. 글로벌 검색**
- [ ] **Cmd+K** (Mac) 또는 **Ctrl+K** (Windows) → 검색 모달 열리는가?
- [ ] 사용자 이름·이메일 입력 → 즉시 결과 (5개 그룹)
- [ ] 결과 클릭 → 해당 페이지로 이동
- [ ] ↑↓ 키 + Enter 작동하는가?

**D-3. Enabler 관리 (`/admin/enablers`)**
- [ ] 승인 대기 Enabler 리스트 보이는가?
- [ ] **승인** 클릭 → 상태 변경 + 사용자에게 알림
- [ ] **거절** 클릭 → 사유 입력 → 처리

**D-4. Enabler 지원 검토 (`/admin/applications`)**
- [ ] 지원자 목록 (탭별: 대기/승인/거절)
- [ ] 승인 클릭 → 가입 링크 이메일 자동 발송
- [ ] 거절 클릭 → 사유 입력 → 안내 이메일 발송
- [ ] CSV 내보내기 버튼 동작하는가?

**D-5. 사용자 관리 (`/admin/users`)**
- [ ] 모든 사용자 리스트
- [ ] 역할 변경 모달 → 저장
- [ ] is_verified 토글
- [ ] CSV 내보내기

**D-6. 기관 관리 (`/admin/organizations`)**
- [ ] 기관 추가 (이름·슬러그·프로그램명·총 크레딧)
- [ ] 편집·삭제
- [ ] 초대 코드 표시

**D-7. 결제 관리**
- [ ] `/admin/credit-packages` — 패키지 추가·편집·삭제
- [ ] `/admin/payment-approvals` — 큰 금액 결제 승인/거절
  - 정책 카드에서 자동승인 임계 + 만료일 설정
- [ ] `/admin/credits` — 모든 거래 이력 + CSV

**D-8. 정산 관리**
- [ ] `/admin/payouts` — 인보이스 목록 + 전월 일괄 생성 버튼
- [ ] 인보이스 상세 → 승인 (Stripe 미설정 시 dry-run 모드) / 취소
- [ ] `/admin/payout-settings` — 글로벌 단가·수수료 편집

**D-9. 문의함 (`/admin/inquiries`)**
- [ ] 새 문의 보이는가?
- [ ] 상세 클릭 → 메시지 전문 + mailto: 답변
- [ ] 답변 완료 / 보관 토글

**D-10. 신고 검토 (`/admin/review-reports`)**
- [ ] 신고된 리뷰 리스트
- [ ] 숨김 처리 → 사이트에서 자동으로 안 보이는가?
- [ ] 기각 → 그대로 보이는가?

**D-11. 분쟁 처리 (`/admin/disputes`)**
- [ ] 사용자가 신청한 분쟁 리스트
- [ ] 상세 페이지 → 양쪽 사용자 정보 + booking 정보
- [ ] 환불액 입력 (전액/부분/0=기각) → 처리
- [ ] 토큰 환불 + Enabler earnings 차감 자동 반영되는가?

**D-12. 공지사항 (`/admin/announcements`)**
- [ ] "새 공지 작성" → 제목·본문·대상(전체/스타트업/Enabler 등)·채널(인앱/이메일)
- [ ] "지금 발송" → 받는 사람들 알림 종에 표시되는가?
- [ ] 이메일 채널 선택 시 메일 도착하는가?

**D-13. 활동 로그 (`/admin/audit-log`)**
- [ ] 관리자 액션 자동 기록 (위에서 한 모든 작업)
- [ ] action / target_type 필터
- [ ] CSV 내보내기

**D-14. 시스템 설정 (`/admin/settings`)**
- [ ] TestLoginPanel 토글 카드 (운영 환경에서만 의미)

## 우리가 알면 좋은 것 (피드백 항목)

각 시나리오에서 다음 5가지를 알려주시면 큰 도움이 됩니다.

1. **막히는 곳** — 무엇을 어떻게 하려다 멈췄는지 (스크린샷 같이)
2. **느린 곳** — 어떤 페이지가 느렸는지 (어림 시간)
3. **이해 안 되는 곳** — 어떤 버튼·메시지가 헷갈렸는지
4. **버그** — 깨지거나 작동 안 한 부분 (어떤 동작 후 어떤 결과)
5. **추천** — 있으면 좋겠다고 생각한 기능
