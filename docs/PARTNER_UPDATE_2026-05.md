# Get It Done at Work — 최근 개발 업데이트 (2026년 5월)

안녕하세요. 지난번 베타 테스트 이후 다음 기능들이 새로 추가됐습니다.
도메인은 그대로입니다: **https://getitdonework.com**

---

## 1. 자동 언어 감지 (한·영)

- **한국에서 접속** → 자동으로 한국어 표시
- **미국에서 접속** → 자동으로 영문 표시
- 우상단 **KO / EN 토글** 버튼으로 직접 변경 가능 (선택은 1년간 기억됨)
- 로그인 후 Enabler 계정은 자동으로 영문, 스타트업/관리자는 한국어로 전환

> 적용 페이지: 홈 / Enabler 찾기 / 회사 소개 / 네비게이션 / 푸터
> (대시보드와 약관 페이지는 한국어 유지)

---

## 2. 회원가입·로그인 보강

- **이메일/비밀번호 회원가입** (Google 로그인은 그대로)
- **비밀번호 찾기** — 등록 이메일로 재설정 링크 발송
- **비밀번호 재설정** — 링크 클릭 시 새 비밀번호 설정 페이지로 이동

---

## 3. 인앱 알림 센터 (종 아이콘)

상단 네비게이션에 **종 아이콘**이 추가됐습니다 (로그인 사용자만).

- 새 알림이 있으면 빨간 배지로 개수 표시
- 클릭하면 최근 알림 목록 (예약 요청·확정·취소, 리뷰, 메시지, 결제, 공지 등)
- 알림 클릭 시 해당 페이지로 바로 이동
- 30초마다 자동 갱신

---

## 4. 실시간 1:1 메시지

스타트업 ↔ Enabler 사이 **실시간 채팅** 기능.

- Enabler 상세 페이지에서 **"1:1 메시지 보내기"** 버튼 클릭
- 상단 네비게이션 **채팅 아이콘**으로 진입
- `/messages` 에서 대화 목록 + 채팅방
- 메시지 도착 시 자동으로 화면에 나타남 + 알림

---

## 5. 프로젝트 관리 (스타트업)

스타트업이 본인 프로젝트를 등록·수정할 수 있습니다.

- `/projects/new` — 새 프로젝트 등록 (제목·카테고리·기간·예산·요구사항)
- `/projects` — 내 프로젝트 목록 (상태별 색상 배지)
- `/projects/[id]` — 상세 보기 + 편집 + 삭제

---

## 6. 결제 시스템 (Stripe 연동, 활성화 대기 중)

**코드는 완성**, Stripe 가맹 가입 + 키 발급 후 활성화됩니다.

흐름:
1. 사용자가 `/credits` 에서 **토큰 패키지 선택** (Starter / Standard / Pro / Enterprise)
2. Stripe 결제창으로 이동 → 카드 결제
3. 결제 완료 시 **자동으로 토큰 잔액 충전**
4. 큰 금액 (예: 100만원 초과)은 **관리자 승인 대기 → 승인 후 충전** (관리자가 임계 설정 가능)
5. 거절 시 **자동 환불** (Stripe API)

관리자 페이지:
- `/admin/credit-packages` — 패키지 가격 관리
- `/admin/payment-approvals` — 큰 금액 결제 승인/거절
- `/admin/credits` — 모든 거래 이력

---

## 7. Enabler 정산 시스템 (Stripe Connect)

세션이 완료되면 자동으로 Enabler에게 정산됩니다.

흐름:
1. Enabler가 `/enabler-dashboard/payouts` 에서 **Stripe Connect 정산 계정 연결** (본인 미국 은행 + W-9/W-8BEN 작성)
2. 매 세션 완료 시 → **자동으로 USD 누적** (관리자 설정 단가 적용)
3. 매월 1일 → **자동으로 인보이스 생성** (관리자가 `/admin/payouts` 에서 확인)
4. 관리자가 **승인** 클릭 → Stripe Transfer 자동 송금 → Enabler 미국 은행 1~2 영업일 입금
5. Enabler에게 정산 완료 이메일 + 영수증

관리자 페이지:
- `/admin/payouts` — 월별 인보이스 검토·승인
- `/admin/payout-settings` — 토큰당 USD 단가, 플랫폼 수수료 (default 20%), 최저 정산액

---

## 8. 검색·정렬 강화 (Enabler 찾기)

`/enablers` 페이지가 더 사용하기 쉬워졌습니다.

- **정렬 옵션 5종** — 추천순 / 평점 높은 순 / 세션 많은 순 / 가격 낮은 순 / 가격 높은 순
- **페이지네이션** — 한 페이지 12명, 다음 페이지 버튼
- 검색 + 카테고리 필터는 그대로

---

## 9. 리뷰 신고·관리

- 부적절한 리뷰가 보이면 **신고 버튼** 클릭 → 사유 선택 (스팸/욕설/허위/기타)
- 관리자가 `/admin/review-reports` 에서 검토 → 숨김 또는 기각
- 숨겨진 리뷰는 자동으로 사이트에서 안 보임 (작성자 본인은 표시 가능)

---

## 10. 분쟁 처리 워크플로

완료된 세션에 문제가 있으면 분쟁을 신청할 수 있습니다.

- 사용자: `/bookings` 에서 완료된 세션 → **"분쟁 신청"** 버튼 → 사유·증빙 입력
- 관리자: `/admin/disputes` 에서 검토 → **전액 환불 / 부분 환불 / 기각** 결정
- 환불 시: 토큰 자동 회수 + 해당 세션 Enabler 적립금도 자동 차감

---

## 11. Enabler 지원 → 자동 가입 흐름

Enabler 지원자가 가입까지 매끄럽게 연결됩니다.

1. Enabler 지원자가 `/enabler-apply` 에서 신청
2. 관리자가 `/admin/applications` 에서 검토 → **승인** 클릭
3. 신청자에게 자동 이메일 발송 (가입 링크 포함, 30일 유효)
4. 링크 클릭 → 회원가입 (이메일 또는 Google) → **자동으로 Enabler 권한 + 프로필 정보 채워짐**
5. Enabler 대시보드로 자동 이동 + 환영 안내

---

## 12. 관리자 도구 강화

운영자가 사용할 도구가 대폭 강화됐습니다.

### 메뉴 정리
좌측 사이드바가 **5개 카테고리**로 그룹화됐습니다:
- **대시보드**: 30일 차트 (신규 사용자 / 세션 / 매출) + 대기 알림
- **사용자**: Enabler / 사용자 / 기관
- **결제·정산**: 거래 / 패키지 / 결제 승인 / 정산 인보이스 / 정책
- **운영 처리**: Enabler 지원 / 문의함 / 신고 검토 / 분쟁 / 공지사항
- **시스템**: 활동 로그 / 설정

### 새 기능
- **공지사항 발송** (`/admin/announcements`) — 전체 또는 특정 그룹(스타트업/Enabler/조직)에 인앱 알림 + 이메일 발송
- **글로벌 검색** — 관리자 모드 어디서나 **Cmd+K** (Mac) 또는 **Ctrl+K** (Windows) → 사용자/예약/지원자/문의/조직 통합 검색
- **활동 로그** (`/admin/audit-log`) — 관리자가 누가 무엇을 언제 했는지 자동 기록 (분쟁 대응용)
- **CSV 내보내기** — 사용자 / 거래 / 인보이스 / 지원자 / 문의 데이터 다운로드
