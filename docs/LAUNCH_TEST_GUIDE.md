## 1. 회원가입 / 인증 (Auth)

- [ ] **이메일 회원가입**: `/signup` → 잘못된 이메일/짧은 비번 입력 시 에러 메시지 노출되는가
- [ ] 정상 가입 → 이메일 인증 메일 수신 → 링크 클릭 → 로그인 가능
- [ ] **Google 로그인**(`Google로 계속하기`) 정상 동작
- [ ] **로그인 실패**: 틀린 비번 입력 시 명확한 에러 메시지("이메일 또는 비밀번호 확인")
- [ ] **비밀번호 재설정**: `비밀번호를 잊으셨나요?` → 메일 수신 → 재설정 → 새 비번 로그인
- [ ] **2FA(2단계 인증)**: 설정(`/settings/security`)에서 활성화 → 로그아웃 → 재로그인 시 코드 요구
- [ ] **로그아웃** 후 보호 페이지(`/bookings`, `/messages`, `/settings`) 접근 시 `/login`으로 리다이렉트
- [ ] **이용약관 동의 모달**: 신규/미동의 계정 로그인 시 약관 동의 모달 노출, `거부` 시 로그아웃

## 2. 스타트업 여정 (핵심 funnel)

### 2-1. Enabler 탐색 → 매칭 요청
- [ ] `/enablers` Enabler 목록/카드 정상 노출 (이름, 소속, **프로필 이미지**, 전문분야, 가능 시간 상태)
- [ ] 필터/검색(학교, 분야 등) 동작
- [ ] Enabler 상세(`/enablers/[id]`) 진입 → 소개·리뷰·가용시간 표시
- [ ] **매칭 요청**(케미스트리/스탠다드/프로젝트) 생성 → 요청 목록에 반영

### 2-2. 크레딧 지급 (Stripe 인증 전 임시 운영)
- [ ] `/credits` 크레딧 안내 페이지 노출 (1 크레딧 = $100)
- [ ] `/credits` 구매 버튼이 **결제 준비 중**으로 비활성화되어 있는지 확인
- [ ] super_admin 로그인 → `/admin/credits` → 실제 스타트업 계정에 크레딧 지급
- [ ] 스타트업 계정으로 다시 확인 → **크레딧 잔액 증가** 확인
- [ ] 잔액 부족 상태에서 예약 시도 → 크레딧 부족 안내가 표시되는지 확인

### 2-3. 예약 → 세션
- [ ] 확정된 매칭에서 **세션 예약**(시간 선택) → `/bookings`에 `확정` 상태로 표시
- [ ] **`/bookings` 필터 탭**(전체/대기중/확정/완료/취소) 카운트 정확, 클릭 시 필터링
- [ ] 예약 시각 **15분 전부터** 입장 버튼 활성화("지금 입장하기"), 그 이전엔 "N분 후 입장 가능"
- [ ] 예약 시각 **90분 경과 후** "세션 시간 만료" 표시 + 입장 불가
- [ ] **⚠️ 모바일(375px)에서 필터 탭이 화면 밖으로 잘리지 않는가** (알려진 이슈 — 아래 8장 참조)

### 2-4. 세션 종료 후 리뷰
- [ ] 완료된 세션에서 **별점+리뷰** 작성 → "리뷰 완료"로 변경
- [ ] 세션 종료 직후 `/bookings?review=<id>` 진입 시 **리뷰 모달 자동 노출** (미작성 완료 세션 한정)
- [ ] 모달 닫기 → 재진입해도 중복 강제 노출 안 됨

## 3. 화상 세션 (LiveKit) — 2인 동시 필요 ⭐가장 중요

> 스타트업 계정(기기 A) + Enabler 계정(기기 B)으로 **동시 접속**해 진행.

- [ ] **입장 전 로비(PreCallLobby)**: 카메라/마이크 미리보기, 권한 요청, 장치 선택
- [ ] 양쪽 모두 입장 → 세션 시작, 상대 영상/음성 정상 수신
- [ ] **세션 헤더**: "세션 진행 중 · 경과 시간(00:00→증가)", "예정 종료" 시각 표시
- [ ] 화면 공유 / 음소거 / 카메라 끄기 등 컨트롤 동작
- [ ] **네트워크 끊김 → 자동 재연결** (Wi-Fi 잠시 끄기 테스트)
- [ ] **탭 닫기/새로고침 시 이탈 경고**(유료 세션 보호) 노출
- [ ] 한쪽이 "세션 종료" → 양쪽 모두 `/meeting/session-ended`로 이동
- [ ] **종료 페이지 CTA**: 스타트업은 "내 예약 보기"(`/bookings`), Enabler는 "대시보드로"(`/enabler-dashboard`)로 분기
- [ ] **5분 미만 종료 시 크레딧 환불** 안내/처리, 5분 이상은 정상 차감
- [ ] 모바일에서 로비/세션 화면 레이아웃 깨지지 않음(버튼 충분히 큼, 비디오 영역 높이 제한)

## 4. Enabler 여정

- [ ] 로그인 → `/enabler-dashboard` 진입
- [ ] **새 매칭 요청(pending)** 수신 → 수락/거절
- [ ] 수락 시 스타트업에 알림, 다가오는 세션 목록에 반영
- [ ] **다가오는 세션** 입장 버튼 상태(15분 전 활성 / 만료 표시)가 스타트업 측과 일치하는가
- [ ] 진행 중(시작~90분 이내) 세션도 목록에 노출되는가
- [ ] 세션 진행 → 종료 → 정산 반영
- [ ] **세무 양식**(W-9 / W-8BEN) 업로드 기능 동작 (미국 전문가)
- [ ] 수익/정산 내역 표시
