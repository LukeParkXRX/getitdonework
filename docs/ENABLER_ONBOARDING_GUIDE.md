# Enabler(전문가) 풀 모집 — 준비 상태 & 실행 가이드

> 목적: 미국 파트너가 공식 오픈 전 전문가들을 가입시켜 **초기 Enabler 풀**을 모을 수 있도록 준비 상태를 점검하고 실행 방법을 정리.
> 점검일: 2026-05-30 · 대상: https://getitdonework.com (프로덕션 실측)

---

## 1. 결론 먼저

전문가 모집 파이프라인은 **준비 완료** 상태이며, 점검 중 발견된 **치명적 블로커 1건은 수정·배포**했습니다.

| 구성요소 | 상태 |
|----------|------|
| 공개 지원폼 `/enabler-apply` | ✅ 작동 (점검 중 발견된 500 오류 **수정 완료**) |
| 회원가입 역할 선택 `/signup` (스타트업/인에이블러) | ✅ 작동 |
| 관리자 지원서 심사 `/admin/applications` | ✅ 작동 (승인/거절/CSV) |
| 관리자 Enabler 관리 `/admin/enablers` | ✅ 작동 |
| 승인→초대링크→가입→공개노출 전체 흐름 | ✅ 구현됨 |
| 테스트 데이터 공개 노출 | ✅ 차단됨 (`SHOW_TEST_DATA=false`) |

> **발견·수정한 블로커**: 익명 방문자가 지원폼/문의폼을 제출하면 서버가 500 오류를 내며 **저장이 안 되던** 문제(RLS 정책 + 행 되읽기 충돌). 두 공개 폼 라우트를 수정해 배포했습니다. 이 수정 전이었다면 파트너가 보낸 전문가들의 지원이 전부 유실됐을 상황입니다.

---

## 2. 전문가가 합류하는 2가지 경로

### 경로 A — 지원서 심사 (권장: 검증된 풀)
```
1) 전문가가 /enabler-apply 폼 작성·제출
     (이름·이메일·학교·학위·지역·전문분야 1개+·자기소개 100자+)
2) 관리자에게 이메일 알림 → /admin/applications 에 "대기중"으로 쌓임
3) 관리자가 검토 후 [승인]
4) 시스템이 자동으로 30일 유효 초대링크를 전문가 이메일로 발송
     ({사이트}/signup?token=...&role=enabler)
5) 전문가가 링크로 가입 완료 → enabler 프로필이 자동 "승인" 상태로 생성
6) /enablers 공개 목록에 즉시 노출
```
**장점**: 파트너/관리자가 한 명씩 검토 후 받아들임 → 품질 관리.

### 경로 B — 직접 가입 (빠른 수집)
```
1) 전문가가 /signup 에서 역할 "인에이블러" 선택 후 가입
2) enabler 프로필이 "대기(pending)" 상태로 생성
3) 관리자가 /admin/enablers 에서 승인
4) /enablers 공개 목록에 노출
```
**장점**: 초대링크 없이 즉시 가입 가능 → 모집 속도. 단 승인은 여전히 필요.

> **추천**: 초기 풀은 **경로 A**(지원서 심사)로 진행. 파트너가 "이 링크(`/enabler-apply`)에서 지원하세요"라고 안내 → 관리자 대시보드에서 한 번에 검토·승인.

## 3. 파트너에게 전달할 안내 (그대로 복붙용)

> **For experts (English):**
> Join Get It Done at Work as an Enabler — apply here: **https://getitdonework.com/enabler-apply**
> You'll be asked for your school, degree, location, areas of expertise, and a short bio (100+ chars). After we review your application, you'll get an email invite link to finish creating your account.

> **전문가용 (한국어):**
> Get It Done at Work Enabler로 합류하기 — 지원 링크: **https://getitdonework.com/enabler-apply**
> 학교·학위·지역·전문분야·자기소개(100자 이상)를 입력하면, 검토 후 가입 완료 초대 메일을 보내드립니다.

---

## 4. 관리자(파트너) 운영 체크리스트

- [ ] `/admin/applications`에서 새 지원서 검토 (대기중 탭)
- [ ] 지원 내용 확인 후 **승인** → 초대 메일 자동 발송 확인
- [ ] 전문가가 초대링크로 가입 완료했는지 `/admin/enablers`에서 확인
- [ ] 가입한 전문가가 `/enablers` 공개 목록에 노출되는지 확인
- [ ] CSV 내보내기로 지원자 현황 관리 (선택)

---

## 5. 오픈 전 남은 권장 조치 (코드 외 / 데이터·정책)

1. **유일한 실제 Enabler 'Luke Park' 프로필 정리**
   현재 공개 목록의 단 1명(계정주 본인 시드)의 학교/학위/전문분야/지역이 모두 "TEST"로 채워져 있음. 실제 값으로 채우거나, 진짜 전문가가 들어오기 전까지 노출에서 내릴지 결정 필요. (실제 정보를 주시면 즉시 DB 반영 가능)

2. **초대 메일 발송 점검(실측 권장)**
   승인 시 자동 발송되는 초대 메일이 실제 수신함에 도착하는지(Resend 설정, 스팸함 여부) 실제 이메일로 1건 테스트 권장.

3. **이메일 인증 정책 확인**
   가입 시 이메일 소유 검증(확인 메일) 강제 여부 점검 권장 — 아무 이메일로 가입되는지 1건 테스트.

4. **지원폼/초대 메일의 영어 카피 점검**
   미국 전문가 대상이므로 EN 카피 자연스러움·오타 확인.

---

## 6. 점검에 사용한 근거 (실측)

- 프로덕션 DB: 승인된 enabler 10명 = 실제 1명("Luke Park") + 테스트 9명. 공개 목록엔 실제 1명만 노출(테스트 차단 정상).
- 공개 지원 API 익명 제출: 수정 전 HTTP 500(RLS), **수정 후 정상 접수**.
- 관리자 심사 UI: `/admin/applications` 승인/거절/CSV/필터 정상, 현재 대기 지원서 0건.
